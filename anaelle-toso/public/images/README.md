# Images du site

Déposer ici les photographies (JPG/WebP, côté long ≈ 2 400 px, < 1 Mo idéalement) :

| Dossier | Usage |
| --- | --- |
| `hero/` | Photo ou vidéo d'ouverture (cheval en pâture au lever du soleil) |
| `camion/` | Photo **détourée** du camion (PNG transparent, profil orienté vers la droite) |
| `histoire/` | Portrait et photos personnelles d'Anaëlle |
| `prestations/` | Une photo par soin (facultatif : un schéma s'affiche sinon) |
| `deroulement/` | Photos des étapes d'une intervention (facultatif) |
| `galerie/` | Galerie : chevaux, interventions, écuries, camion, matériel, coulisses |
| `instagram/` | Galerie manuelle des réseaux sociaux |
| `avis/` | Photos des chevaux des témoignages (avec accord) |

Puis renseigner le chemin (ex. `/images/galerie/cheval-01.jpg`) dans l'administration ou dans
`content/*.json`. L'optimisation (AVIF/WebP, tailles adaptées) est automatique.
